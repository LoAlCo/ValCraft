The ValCraft instance (instances/ValCraft) runs Minecraft 26.3 with Fabric Loader, Fabric API
(Apache-2.0, https://github.com/FabricMC/fabric) and the ValCraft Fabric mod (MIT).
Minecraft, Java and Fabric Loader are downloaded by Prism after you sign in with a Microsoft account
that owns Minecraft: Java Edition; they are not included.
